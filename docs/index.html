开始演示

在原型左下角打开“148 · 本轮交互演示”或“演示设置”，查看多AI、角色权限、未读消息和运行状态。点击模块图标进入列表，点击旁边红色数字进入对应未读内容。

这是交互原型；OSS、AI执行、审批、消息发送、会议与系统通知为本地模拟。不同浏览器和域名的演示数据及已读状态独立。
