## 快速体验

150的“交互演示 → 多 AI 筛选演示”可载入已读、正常SLA和多AI数据。

直接打开在线原型；不需要安装或登录。演示身份不是生产账号。不同浏览器/域名的本地状态独立，可以从左下角“150 · 交互演示”和“150 · 演示设置”载入多AI、角色、未读和运行示例。

下载单文件HTML后可本地打开；推荐通过HTTP服务体验，避免浏览器对本地文件存储/下载的限制：

```sh
python3 -m http.server 8147
```

然后打开 `http://127.0.0.1:8147/docs/prototype.html`。页面有一处远程后台品牌图片；核心原型脚本和样式已内嵌，图片不可达不影响业务操作。

## 源码与构建

150不是手工维护的孤立HTML：它由149固定基线和`.prototype150/`模块生成。请修改相应源码模块并重建，不要只修改生成文件。

```sh
npm ci
npm run build
npm test
npm run verify
```

要求Python3及Node.js >=22.12。只查看HTML不需要安装这些工具。`npm test`在隔离DOM内运行，不请求真实业务系统。

`main`分支的`docs/`为GitHub Pages发布目录。提交必须包含重建的HTML、docs产物及相关MD；合并/推送main后GitHub Pages自动更新。固定版本入口在`docs/versions/`，基线142–149不要覆盖。后续新增151时应新增固定文件、更新构建/版本清单和首页，不删除历史版本。

## 能力边界

本仓库是公开的交互原型。AI回答、OSS/SLA、审批执行、消息/邮件/短信、拨号、会议和系统通知为本地模拟或界面说明；不连接生产账号、不执行真实设备动作。浏览器本地数据不会因为上传Git而变成多人共享后端。

不要把生产日志、真实客户资料、密码、Token、浏览器缓存或导出的本地演示状态提交到仓库。仓库包含既有品牌及演示内容，不附加对第三方品牌的授权声明。

150：提醒可关闭/恢复，协作默认收起；运行显示loading，完成显示蓝点和阅读状态。点击标题打开关联会话，展开结果保留原位阅读。阅读筛选为全部、仅未读、仅已读。
