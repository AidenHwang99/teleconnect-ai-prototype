## 快速体验

打开原型左下角唯一的“演示面板”：选择身份、AI和场景，再按步骤准备、推进、查看或完成。包含会话协作、定时服务、审批待办、SLA催办、未读联动、权限范围和文件问答。高级检查与数据工具默认折叠，不再区分演示交互/演示设置的版本。

AI助手展示运行中的会话和服务；整体状态、当前环节与个人职责分别筛选。不同浏览器的本地数据和已读状态独立。

下载单文件HTML后可本地打开；推荐通过HTTP服务体验，避免浏览器对本地文件存储/下载的限制：

```sh
python3 -m http.server 8147
```

然后打开 `http://127.0.0.1:8147/docs/prototype.html`。页面有一处远程后台品牌图片；核心原型脚本和样式已内嵌，图片不可达不影响业务操作。

## 源码与构建

155不是手工维护的孤立HTML：它由154固定基线和`.prototype155/`模块生成。请修改相应源码模块并重建，不要只修改生成文件。

```sh
npm ci
npm run build
npm test
npm run verify
```

要求Python3及Node.js >=22.12。只查看HTML不需要安装这些工具。`npm test`在隔离DOM内运行，不请求真实业务系统。

`main`分支的`docs/`为GitHub Pages发布目录。提交必须包含重建的HTML、docs产物及相关MD；合并/推送main后GitHub Pages自动更新。固定版本入口在`docs/versions/`，基线142–154不要覆盖。后续新增156时应新增固定文件、更新构建/版本清单和首页，不删除历史版本。

## 能力边界

本仓库是公开的交互原型。AI回答、OSS/SLA、审批执行、消息/邮件/短信、拨号、会议和系统通知为本地模拟或界面说明；不连接生产账号、不执行真实设备动作。浏览器本地数据不会因为上传Git而变成多人共享后端。

不要把生产日志、真实客户资料、密码、Token、浏览器缓存或导出的本地演示状态提交到仓库。仓库包含既有品牌及演示内容，不附加对第三方品牌的授权声明。
